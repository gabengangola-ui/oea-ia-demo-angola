# OEA · IA na Engenharia · Demo Angola

Modelos sintéticos para o VI Congresso da Ordem dos Engenheiros de Angola.

## Abrir agora

1. Clica em **index.html** neste repositório.
2. Clica **Raw** e guarda, ou abre GitHub Pages (Settings → Pages → Deploy from branch `main` / `/`).
3. Página prevista: https://gabengangola-ui.github.io/oea-ia-demo-angola/

## Local

```bash
git clone https://github.com/gabengangola-ui/oea-ia-demo-angola.git
cd oea-ia-demo-angola
# qualquer browser
xdg-open index.html
```

Não precisa de Node, Python nem API.

## O que há dentro

- Oil & Gas: índice de desvio (z-score) em pressão / temperatura / vibração. Limite 3. Alerta ≠ paragem.
- Agricultura: 6 talhões, humidade vs limiar, chuva 48 h. O modelo não abre válvulas.
- Caderno 120 vs 150 dias.

Dados fictícios. Sem validade operacional.
